# عمق تاریخچه — اندازه‌گیری واقعی (SPEC.md بخش ۴.۱)

اندازه‌گیری‌شده در ۲۰۲۶-۰۹-۱۵ روی سرور ویندوز MT5 (`82.115.26.25`)، از طریق `mt5.copy_rates_from_pos(symbol, timeframe, 0, 10_000_000)`.

**زمینه:**
- بروکر / ترمینال: `WM Markets Ltd` — `WM Markets MT5 Terminal` (build 6191)، نصب در `C:\Program Files\WM Markets MT5 Terminal`
- حساب: **دمو** (`WMMarkets-Demo`, login `20254070`) — نه لایو. اگر عدد بعداً روی حساب لایو متفاوت بود، باید دوباره اندازه‌گیری شود.
- نماد دقیق طلا: **`XAUUSD@`** (تنها نسخه موجود؛ `XAUAUD@` و `XAUEUR@` هم هستند ولی نامرتبط‌اند، ابهامی در انتخاب نبود)
- `Tools → Options → Charts → Max bars in chart` روی **Unlimited** تنظیم شد (کاربر از طریق Remote Desktop انجام داد) و ترمینال ریستارت شد. قبل از این تنظیم، `copy_rates_from_pos` دقیقاً روی مقدار قبلیِ `maxbars` (۱۰۰٬۰۰۰) سقف می‌خورد (`Terminal: Invalid params` برای هر درخواست ≥ ۱۰۰٬۰۰۰) — با تست مستقیم (نه حدس) تایید شد که این تنظیم واقعاً API را هم محدود می‌کند، نه فقط نمایش چارت.

## جمع‌بندی برای تصمیم `nn_forecaster` (طبق جدول CLAUDE.md / SPEC.md ۴.۱)

عدد مبنا برای این تصمیم، تعداد کندل **M5** است (تایم‌فریم پایه تحلیل طبق تصمیم D2):

> «بیش از ۵۰۰ هزار کندل M5 → بیش از ۵ سال → **وضعیت ایده‌آل**»

با **534,955** کندل M5 روی بیش از ۷.۵ سال، این سرور/حساب در بالاترین دسته‌ی جدول قرار می‌گیرد. شبکه عصبی سری‌زمانی (`nn_forecaster`, بخش ۴.۱۲) از نظر عمق داده **کاملاً شدنی** است — هیچ مانعی برای شروع آن (بعد از فازهای قبلی‌تر طبق ترتیب کار CLAUDE.md) از این جهت وجود ندارد.

**نکته احتیاطی:** این عدد از یک حساب دمو آمده. قبل از شروع واقعی `mt5_bridge` (بک‌فیل کامل) باید تایید شود که حساب دمو همان عمق تاریخی حساب لایو همین بروکر را می‌دهد — بروکرها معمولاً این را برای فلزات/فارکس اصلی یکسان نگه می‌دارند، ولی این فرض تایید نشده است و باید قبل از فاز ۱ بررسی شود.
